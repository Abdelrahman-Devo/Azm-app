عزم | AZM — نسخة قابلة للتثبيت على الهاتف (PWA)

طريقة النشر:
1) ارفع كل محتويات هذا المجلد إلى جذر مستودع GitHub باسم azm-habit-tracker.
2) من Settings > Pages اختر Deploy from a branch ثم main و /(root) ثم Save.
3) انتظر ظهور رابط GitHub Pages.
4) افتح الرابط من Google Chrome على Android.
5) من قائمة ⋮ اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".

مهم:
- يلزم نشر الموقع على HTTPS حتى يعمل التثبيت والعمل دون اتصال.
- البيانات محفوظة محليًا في نفس المتصفح/الجهاز حاليًا.
- هذه نسخة PWA قابلة للتثبيت، وليست APK أصلية بعد.
